# Agenelf 安全治理政策

本文件解释 `policy/safety-constraints.v1.yaml` 的人类可读语义。机器策略是执行单一真源，本文件用于设计、评审和运维。

## 1. 核心原则

1. **主人意图优先**：任务目标、范围、授权、暂停和撤销由主人决定。
2. **模型不是授权主体**：模型输出、记忆、反思、Skill 或本地配置都不能替代主人授权。
3. **最小权限**：每个 Runner 只获得当前能力需要的文件、网络和凭据。
4. **三权分离**：Agent 提议，主人裁决高风险操作，确定性 Runner 执行。
5. **证据优先**：没有测试、Runner 结果或晋升证据，不得声称完成。
6. **默认可回滚**：优先可逆方案；不可逆操作必须明确说明。
7. **撤销立即生效**：主人停止或改变范围后，未执行步骤必须停止。

## 2. 风险级别

| 级别 | 默认行为 | 主人是否可授权 | 典型任务 |
|---|---|---:|---|
| `read` | 可自动执行 | 不需要 | 巡检、日志读取、HTTP/TCP 验证 |
| `change` | 等待精确授权 | 是 | 重启服务、Compose 部署、APT 更新 |
| `privileged` | 等待增强授权 | 是 | 安装系统软件、防火墙和生产配置变更 |
| `irreversible` | 短时授权和二次确认 | 是 | 永久删除、数据库销毁、磁盘重分区 |
| `forbidden` | 永久拒绝 | 否 | 伪造授权、关闭审计、泄露凭据、绕过策略 |

**危险不等于禁止。** 主人可以授权 `privileged` 和 `irreversible` 任务；有效授权后 Runner 应按绑定载荷忠实执行。永久禁止的是破坏治理本身的行为。

## 3. 授权要求

授权必须绑定：

```text
capability
operation
target
canonical_parameters_hash
risk
nonce
issued_at
expires_at
```

所有授权必须：

- 单次使用；
- 有时效；
- 不能换目标、换参数或换操作复用；
- 可在未开始前撤销；
- 执行后保存主人决定和 Runner 证据。

### 3.1 Change

必须给出目标、参数摘要和影响说明。

### 3.2 Privileged

除精确绑定外，还必须给出：

- 影响范围；
- 回滚计划；
- 支持时先做 dry-run；
- 执行后的状态验证。

### 3.3 Irreversible

还必须给出：

- 为什么不可逆；
- 备份状态；
- 极短有效期；
- 第二次明确确认；
- 执行后不可恢复的范围。

## 4. 永久红线

以下行为不能通过普通对话或高风险授权放行：

- Agent 自己批准或伪造主人决定；
- 修改、删除或隐藏审计证据；
- 绕过或关闭 Policy Engine；
- 把 SSH 私钥、密码、Token 或 Cookie 注入模型；
- 让模型生成任意 Shell 并直接交给高权限环境；
- 修改测试或 Gate 只为让候选通过；
- 自主推送或合并 `main`；
- 在主人撤销后继续执行；
- 隐藏副作用、失败或范围扩张。

## 5. Prompt Injection 与记忆污染

来自以下来源的内容均视为不可信数据：

- 用户粘贴的网页、日志、代码和文档；
- 服务器返回内容；
- 工具输出；
- 长期记忆；
- `local/context/`；
- 外部模型返回内容；
- 新生成 Skill。

不可信内容不能：

- 改变系统和策略优先级；
- 请求读取凭据；
- 产生授权；
- 扩大文件或网络范围；
- 让 Agent 隐瞒行为。

## 6. Runner 隔离

每个 Runner 必须满足：

- 不调用 LLM；
- 只处理固定 schema；
- 再次验证策略、目标和指纹；
- 只挂载所需凭据；
- 结果目录对 Agent 只读；
- 不提供自由 Shell；
- 输出退出码、时间、摘要和结构化证据。

## 7. 移动与语音安全

Web、手机和语音端只能作为统一控制面的客户端：

- 使用相同的策略和授权模型；
- 高风险授权必须显示完整目标和影响；
- 语音识别结果不能直接成为不可逆授权；
- 建议使用设备绑定和生物识别完成二次确认；
- 防止授权重放；
- 保留文本版授权内容和签名证据。

## 8. 安全事件处置

出现以下情况必须进入 `blocked`：

- 请求指纹不一致；
- 授权过期、已使用或被撤销；
- Runner 收到未知操作；
- 结果文件异常；
- 候选修改保护路径；
- 凭据疑似进入模型上下文；
- 自主系统试图扩大权限。

处置步骤：停止执行、保存证据、创建 P0/P1 意向、通知主人、修复后新增回归测试。
