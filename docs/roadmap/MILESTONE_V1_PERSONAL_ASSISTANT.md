# Milestone V1 Personal Assistant

## 目标

让 Agenelf 从能力集合升级为可靠私人助理。

## 必须具备

### 任务管理

- 理解自然语言目标
- 自动拆解步骤
- 保存任务状态
- 支持暂停和恢复

### 服务器助理

- 多服务器清单
- 巡检任务
- 部署任务
- 验证任务
- 回滚任务

### 开发助理

- 代码分析
- 修改建议
- 测试执行
- 修复验证

## 不允许

- 隐藏执行
- 无审计修改
- 绕过授权
- 把秘密发送给模型

## 验收

每个能力必须提供：

1. 自动化测试
2. 失败证据
3. 回滚方案
4. 文档
5. 安全规则

## 后续

完成 Workflow 基础后，再进入：

- Mobile App
- Voice Gateway
- 主动式个人管家
