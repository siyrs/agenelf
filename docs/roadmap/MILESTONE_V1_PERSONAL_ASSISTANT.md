# Milestone V1：可靠私人助理

## 目标

让 Agenelf 从能力集合升级为可靠私人助理：能保存主人长期目标，组合多个能力，暂停恢复，在高风险节点等待授权，并用可信证据证明结果。

## 当前实施状态

### 任务管理

- [x] 持久化长期任务；
- [x] 主人目标、步骤、验收条件、证据计划；
- [x] 状态机、暂停、恢复、取消、失败重试；
- [x] 步骤依赖与审批等待；
- [x] 可信证据完成门；
- [x] 多端 revision 并发保护；
- [ ] 后台调度与定时触发；
- [ ] 通用 DAG 并行和补偿执行器。

### 服务器助理

- [x] 多服务器 allowlist；
- [x] 结构化巡检、Docker、systemd、apt、Compose 操作；
- [x] 精确绑定主人授权；
- [x] HTTP/TCP 验证 Runner；
- [x] Workflow 可引用 `op-` 与 `val-` 证据；
- [ ] 跨服务器批次编排、并发限流和统一回滚；
- [ ] 数据库备份/恢复能力域。

### 开发助理

- [x] 受控 `app-tmp -> tests -> gate -> promote` 自主改进链；
- [x] 测试和晋升摘要绑定；
- [x] 任务可引用测试与晋升证据；
- [ ] 通用外部仓库 `code.repair` 工作区；
- [ ] PR 审查、变更集和回滚补丁能力；
- [ ] 多语言构建矩阵。

### 多模型

- [x] DeepSeek/GPT/GLM/Ollama 配置模板；
- [x] 按能力、成本、隐私和就绪状态确定性路由；
- [x] API Key 环境变量引用和脱敏目录；
- [x] 本地隐私路由；
- [ ] 将路由结果接入统一动态 ModelClient；
- [ ] Token、费用、延迟和质量在线评测闭环。

### Web、手机与语音

- [x] CLI/HTTP/Web/Mobile/Voice 统一命令信封；
- [x] actor/session/idempotency 绑定与防重放；
- [x] 授权仅使用 ID 引用；
- [x] 输入脱敏和安全元数据白名单；
- [ ] Web/PWA 任务与审批界面；
- [ ] Android/iOS 客户端；
- [ ] ASR/TTS Voice Gateway；
- [ ] 设备登录、推送通知和高风险二次确认 UI。

## 不允许

- 隐藏执行；
- 无审计修改；
- 绕过授权；
- 把秘密发送给模型；
- 因来自手机或语音而自动提升权限；
- 没有 Runner、测试、验证或晋升证据就宣称完成。

## V1 验收门

V1 可宣布完成前，至少要达到：

1. 一个真实多服务器任务从 Task Engine 建立到验证完成；
2. 一个真实代码 Bug 在隔离工作区修复、测试并形成 PR；
3. 一个 Web 或 Mobile 客户端通过统一命令信封管理任务和审批；
4. DeepSeek 默认路由与一个备用云模型、一个本地模型完成故障切换实测；
5. 安全回归、恢复演练和凭据泄漏测试全部通过。

本轮完成的是 V1 的**核心控制面基础**，不是整个私人管家终态。
